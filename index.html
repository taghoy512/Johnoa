Mathematical Expression

Topic 2

Translating Phrases

1. Sum of a number and 10 → x + 10
2. Difference of a number and 5 → x − 5
3. Product of 10 and a number → 10x
4. Quotient of a number and 50 → x / 50
5. One-fifth of a number → (1/5)x
6. Three-fourths of 500 → (3/4)×500
7. Sum of two numbers less 11 → (x+y)−11
8. Double sales less taxes → 2x − y
9. Difference of gross sales less taxes → x − y
10. A number subtracted from 8 → 8 − x

Sample Problems

Sum = 45, difference = 11 → x = 17, y = 28
Average of quizzes = 85, first is 10 higher → 80 and 90
3x + 7 = 34 → x = 9
Two grades total 180, one has 14 more → 83 and 97

Sets

Topic 3

Definition

A set is a group or collection of objects. The objects are called elements.

Letters in ALEX EALA → A = {A, E, L, X}

Fundamental Number Sets

Natural Numbers
ℕ = {1, 2, 3, 4, 5, …}
Whole Numbers
𝕎 = {0, 1, 2, 3, 4, …}
Integers
ℤ = {…, −2, −1, 0, 1, 2, …}
Rational – terminating & repeating decimals
Irrational – non-terminating & non-repeating
Real Numbers – all rational + irrational

Set-Builder Notation

Topic 4

Form

{ x | P(x) }   or   { x : P(x) }

“The set of all x such that P(x) is true.”

Examples

Natural numbers > 10 and < 15
{ x ∈ ℕ | 10 < x < 15 } = {11, 12, 13, 14}
Counting numbers > 5 and ≤ 10
{ x ∈ ℕ | 5 < x ≤ 10 } = {6, 7, 8, 9, 10}
Very useful for large or infinite sets.

Different Types of Sets

Topic 5
Well-Defined – elements can be clearly identified
Empty / Null – no elements (∅)
Finite – limited elements (e.g. {1,2,3,4})
Infinite – unending (e.g. whole numbers)
Equal – exactly the same elements
Equivalent – same number of elements
Universal (U) – all elements being considered
Complement (A′) – elements in U but not in A
Proper Subset (⊂) – A is inside B and A ≠ B
Improper Subset (⊆) – A can equal B

Set Operations

Topic 6

Intersection (A ∩ B)

Common elements only.

A = {1,2,3,4}
B = {2,3,5,6,7}
A ∩ B = {2, 3}

Union (A ∪ B)

All elements from both sets.

A = {1,2,3,4}
B = {3,4,5}
A ∪ B = {1, 2, 3, 4, 5}

Disjoint

No common elements (A ∩ B = ∅).

Venn Diagram

Topic 7

What is it?

A diagram that uses circles inside a rectangle (universal set) to show relationships between sets.

Key Regions

  • A ∩ B – overlapping part only
  • A ∪ B – everything in A or B
  • A′ – outside of A
  • B ∪ C – everything in B or C
  • B′ ∩ C – part of C outside B
Draw the rectangle (U) first, then the circles.

Reasoning

Topic 8

Deductive Reasoning

General → Specific (conclusion is certain if premises are true)

All humans are mortal.
Alexis is a human.
∴ Alexis is mortal.
All even numbers are divisible by 2.
22 is even.
∴ 22 is divisible by 2.

Inductive Reasoning

Specific → General (conclusion is probable)

2+1=3, 4+1=5, 6+1=7 (all odd)
Conclusion: Even number + 1 is always odd.
